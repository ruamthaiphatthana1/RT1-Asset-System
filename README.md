# RT1-Asset-System

ระบบยืม–คืนครุภัณฑ์และอุปกรณ์ของโรงเรียนแบบ Responsive ประกอบด้วย
- หน้าเว็บ: GitHub Pages (`web/`)
- ระบบหลังบ้านและ API: Google Apps Script (`gas/`)
- ฐานข้อมูล: Google Sheets
- รูปภาพ เอกสาร และลายมือชื่อ: Google Drive

## ความสามารถหลัก
- แอดมินเป็นผู้สร้างบัญชีทั้งหมด ไม่มีหน้าสมัครสมาชิก
- บทบาท: แอดมิน เจ้าหน้าที่พัสดุ ผู้บริหาร ครู นักเรียน และผู้ตรวจนับ
- ทะเบียนครุภัณฑ์รายชิ้นและอุปกรณ์ยืมตามจำนวน
- สร้าง QR Code/Barcode และพิมพ์สติกเกอร์
- ผู้ยืมส่งคำขอ เจ้าหน้าที่/ผู้บริหารอนุมัติตามเงื่อนไข
- นักเรียนต้องให้ครูผู้รับผิดชอบรับรองได้
- เจ้าหน้าที่สแกนจ่ายและรับคืน พร้อมลายมือชื่อและภาพสภาพ
- คืนบางส่วน ชำรุด สูญหาย คืนล่าช้า แจ้งซ่อม และตรวจนับ
- รายงาน กราฟ Audit Log และปรับธีมจากหน้าแอดมิน

## ข้อสำคัญ
- อัปโหลดเฉพาะ **เนื้อหาภายในโฟลเดอร์ `web`** ไปยัง GitHub Pages
- ห้ามอัปโหลดข้อมูลจาก Google Sheet, ไฟล์ลายมือชื่อ หรือรหัสผ่านขึ้น GitHub
- ค่า `API_URL` อยู่ที่ `web/assets/js/config.js` และต้องเป็น URL ที่ลงท้ายด้วย `/exec`
- Google Sheet และโฟลเดอร์ Drive ต้องคงสถานะเป็นส่วนตัว
- URL ของ Apps Script เป็นปลายทางสาธารณะ แต่ทุกคำสั่งที่มีข้อมูลต้องผ่าน session และสิทธิ์จากฝั่งเซิร์ฟเวอร์
